# SNEP — Secure Network Exchange Protocol

SNEP is a foundational protocol for decentralized, secure, and verifiable data transfer. It allows:

- Verifiable content provenance
- Local-first caching & delta-sync
- Revocable, shareable access

This repository contains:

- Reference Python server
- Python SDK
- Demo showing signed, verifiable data
- Minimal spec

Use `demo/demo_app.py` to test.
